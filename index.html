JavaScript Basics

  • Підключення JavaScript у тегу <head> — код виконується перед завантаженням сторінки. Використовується рідко, зазвичай для аналітики чи службових скриптів.
  • Підключення JavaScript у тілі сторінки (<body>) — скрипт виконується під час завантаження сторінки. Може взаємодіяти з елементами, які вже є в DOM.
  • Підключення зовнішнього файлу через атрибут src — основний і правильний спосіб. Код зберігається у окремому файлі (наприклад, js/main.js) і підключається наприкінці сторінки перед </body>.
